## SKIP 紀錄

### MT-M2-004：year_cnt numeric backfill

**SKIP 原因**：test designer 設計時誤用 `year_cnt`（numeric）作為 M2 backfill 範例，但 ob_list_definition entity 並無 `year_cnt` 欄位；5a backward-compat 範圍只 5 個 categorical entity column（`prod_kind` / `caseyear` / `spec_tp` / `case_status` / `settle_src`）。

m282 backfill 邏輯只支援 categorical（split `$$` → values）；numeric / date 不在 5a 範圍。

若日後 5b/5c 補入 numeric backward-compat（如將月名單分派 Stage 1 numeric pool data 欄位納入 ob_list_definition 持久化），需另寫新 migration + 新 test case，不重用 MT-M2-004 標籤。
