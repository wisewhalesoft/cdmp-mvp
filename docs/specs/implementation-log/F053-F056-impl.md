## 重要技術設計

### 後端 service

| 主題 | 實作 |
|---|---|
| 覆寫式 PUT dimensions | `scoreRepo.delete(...)` → `scoreRepo.save(newRows)`；card_version 不遞增 |
| 區間重疊驗證 | `hasNumericOverlap` / `hasStringIntervalOverlap` 純函式；半開合法（score_e+1 = 下一級 score_s） |
| 月跑鎖 | `assertNotLocked()` 共用 helper；In(['pending','running']) |
| audit log entity_id | dimensions: `H\|1\|ACCOUNT_AGE`、card-levels: `H\|1`、tier: `H\|A` 或 `M5\|`（fallback） |
| DISABLE action cast | 沿用 F068 pattern：`'DISABLE' as 'DELETE'`（DB schema varchar(10) 容許） |
| F056 fallback 跳過 active 驗證 | `cardLevel == null` 短路 `assertCardLevelExistsOrFallback` |
| F056 BR-9 | `cardLevel.length > 1` 直接拋 CARD_LEVEL_NOT_FOUND（VARCHAR(1) vs VARCHAR(5) 不對稱保護） |
| F056 findTierByPk | cardLevel=null 時用記憶體 `.find()`，避免 TypeORM where {x: null} 轉成 SQL `=NULL` 不 match |
| preview 計算來源 | `ob_pool_data_list.score`（既有計算結果套用新門檻），非實時呼叫 fn_calc_tier_level |
| 跨層 fn_calc_tier_level | `describe.skipIf(process.env.DB_TYPE !== 'postgres')` 條件跳過 SQLite |

### 前端

| 主題 | 實作 |
|---|---|
| 版本選擇器 | cardType 切換 6 選（H/S/E/S5/E5/M）；cardVersion 鎖 active（覆寫式設計） |
| 月跑鎖偵測 | API 回 409 SCORING_VERSION_LOCKED 時 `setIsLocked(true)` 顯示 banner + 所有寫入按鈕 disabled |
| 422 Modal 不關閉 | `runWriteOp` 一律 throw 給呼叫端，Modal 內 catch 設 formError，Modal 保留 |
| Fallback 顯示 | `cardLevel === null` 列套 `bg-purple-50/60` + Fallback 標籤；M5/M3/HC/C3 在 prototype banner 中明確說明 |
| 區間重疊紅框 | 422 後設 errorMap，input 套紅色邊框 + 底部 inline 警告 |
| Preview debounce | 300ms 後呼叫 GET preview，並用 distribution.A/B/.. 計算百分比 progressBar |
| Toast | success / error 雙色（emerald / red），2.5 秒自動消失 |
| CARD_LEVEL 下拉動態 | TierAddModal 依 `levels` prop 動態列出（含 fallback 空 option） |

| Entity | 變更 |
|---|---|
| `ob-levelcard-version` / `column` / `score` / `level` | `created_at` / `updated_at` 改 `dateColumnType`；surrogate PK 改 `surrogatePkType` |

| `ob-tier` | surrogate PK 改 `surrogatePkType` |

| `assignment-run` | timestamp 欄位改 `dateColumnType` |
| `common/database/column-types.ts` | 新增 `surrogatePkType` helper（PostgreSQL=bigint / sqlite=integer） |
