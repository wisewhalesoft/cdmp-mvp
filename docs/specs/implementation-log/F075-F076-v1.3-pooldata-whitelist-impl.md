## F076-C 軟停用機制驗證（v1.3 PO 決議落地）

| 驗證點 | 機制 | TC |
|-------|------|-----|
| 同 transaction | service `dataSource.transaction(cb)` 包覆 field update + option 批次 UPDATE | TC-FIELD-TYPE-SWITCH |
| categorical → numeric | service 內檢查 `wasCategorical && !willBeCategorical` 才觸發 | TC-FIELD-TYPE-SWITCH |
| categorical → date | 同上邏輯支援 | TC-FIELD-TYPE-SWITCH（参 helper） |
| numeric → categorical | 不觸發批次軟停用（防止 false trigger） | TC-FIELD-TYPE-SWITCH-2 |
| categorical → categorical | 不觸發（即使 displayName 改） | TC-FIELD-TYPE-SWITCH-3 |
| 批次 UPDATE 內容 | SET is_active=false, deactivation_reason='field_type_changed', updated_at=now WHERE column_name=:c AND is_active=true | service line 174~183（QueryBuilder） |
| 稽核 details | after_value.deactivatedOptionCount = N | TC-FIELD-TYPE-SWITCH 驗 audit |
| getInactiveCount API | UI confirm Modal 預查「將自動停用 N 個可選值」 | TC-GET-INACTIVE-COUNT |
| F076 端點不接受 'field_type_changed' | DeactivatePooldataOptionDto 僅允許 reason 字串、deactivation_reason 由 service 寫死 'manual' | service line 209 + DTO 設計 |
