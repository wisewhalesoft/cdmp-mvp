## 元件清單

### 1. exceljs 依賴審核 + 安裝
- **選型結果**：exceljs ^4.4.0（vs SheetJS / xlsx-populate / write-excel-file）
- **理由**：原生 streaming（stream.xlsx.WorkbookWriter）、TypeScript types、活躍維護、Node server-side 業界標準
- **安裝**：`npm install exceljs@^4.4.0 --save`（package-lock.json 已更新）
- **驗證**：`require('exceljs').stream.xlsx` 可用，版本 4.4.0

### 2. F064 xlsx 主路徑
- `AssignmentRunReportService.exportResult(runId, 'xlsx', actorId, actor, options)`
- 8 欄位（list_no / appl_no / card_level / tier_level / dept_id / emplid / score / is_cr）共用常數 EXPORT_HEADER
- header style：粗體
- filename: `assignment_result_{YYYYMM}_{run_id 前 8 碼}.xlsx`
- contentType: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- audit log: action='EXPORT', after_value={format:'xlsx', rowCount}

### 3. Streaming pattern
```
PassThrough sink → ExcelJS.stream.xlsx.WorkbookWriter
  → sheet.addRow(...).commit() 逐筆 flush
  → sheet.commit() / workbook.commit() 觸發 ExcelJS close stream
  → sink 'end' 事件解 promise → Buffer.concat(chunks)
```
- 50,001 筆 1.1 秒完成，memory delta < 500MB
- `useSharedStrings: false` 避免 sharedStrings.xml 累積記憶體
- 不阻塞 event loop：每筆 addRow().commit() 為 async 友善的 sync 呼叫，workbook.commit() 內部 awaitable

### 4. EXPORT_FILE_EXPIRED watchdog 策略
- 採用 **Promise.race(writeAndFinish, timeoutPromise)** in-process timeout（非 OS-level cron）
- 預設 `EXPORT_TIMEOUT_MS_DEFAULT = 5 * 60 * 1000`（spec F064 BR-3）
- 可透過 `options.timeoutMs` 覆寫（測試使用 1ms 驗證 expired 路徑）
- timeout 觸發 → 500 InternalServerErrorException with `{error: EXPORT_FILE_EXPIRED}`
- timeoutHandle 用 `unref()` 避免 timer 阻擋 process exit
- **未實作（留下輪）**：暫存檔 + TaskScheduler cron 清理。本實作不落地暫存檔（記憶體 buffer 直接回傳），所以無檔案需要清理；若未來改 disk-based streaming download，再加 watchdog cleanup。

### 5. F067 mismatch xlsx
- `AssignmentRunReportService.compareRunsExport(runA, runB, actorId, actor, options)`
- 重用 `compareRuns()` 已計算 CompareResponse
- 3 sheets：
  - `summary`: metric/base/compare/diff（totalCases + dept_* + level_* + personnelMismatchRate）
  - `personnelMismatch`: appl_no/base_emplid/compare_emplid（NFR-005 主驗收清單）
  - `customerDiff`: change(added/removed)/appl_no
- Controller: GET `/api/v1/assignment/runs/compare?runA=...&runB=...&export=xlsx`
- audit log: entity_id=baseRunId, after_value={format:'xlsx', rowCount, compareRunId}

### 6. Controller 整合
- `AssignmentRunController.exportRun`：原邏輯不變（passthrough out.body 給 res.send，express 自動支援 string/Buffer）
- `AssignmentRunController.compareRuns`：新增 `export=xlsx` 分支，passthrough: true 切換手動 res 寫入
- DTO `CompareRunsQueryDto.export?: 'xlsx'`（IsIn validator）
