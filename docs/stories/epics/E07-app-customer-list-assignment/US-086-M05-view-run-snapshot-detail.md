# US-086：查看執行快照詳情

> **Story ID**：US-086
> **Epic**：[E07 — 客戶名單分派](epic-brief.md)
> **模組**：M05 快照歷史
> **優先級**：Must Have
> **階段**：Phase 1（MVP）
> **預估點數**：5

---

## User Story

**As a** 業務主管
**I want** 查看特定月跑的三份執行快照詳細內容
**So that** 可完整追溯當時的執行設定、輸入名單與分派結果，作為稽核依據或問題排查參考

---

## 驗收標準

### AC-1：顯示快照總覽

- **Given** 業務主管從歷史清單進入某月跑的詳情頁
- **When** 頁面載入完成
- **Then** 顯示月跑基本資訊（run_id、作業年月、觸發者、執行時間、狀態）
- **And** 顯示三個快照分頁索引：「設定快照」、「輸入名單快照」、「結果快照」

### AC-2：查看設定快照（config）

- **Given** 業務主管點擊「設定快照」分頁
- **When** 分頁內容載入
- **Then** 顯示本次執行時所使用的完整設定參數：
  - 計分版本號與備註
  - 各部門比例設定（表格呈現）
  - 各部門人員比例設定（可收合的巢狀表格）
  - CR 回分規則狀態（啟用/停用）

### AC-3：查看輸入名單快照（input_list）

- **Given** 業務主管點擊「輸入名單快照」分頁
- **When** 分頁內容載入
- **Then** 顯示 Stage 1 的原始名單摘要：總筆數、各 Stage 分類筆數
- **And** 提供搜尋功能，可依客戶編號查詢是否在輸入名單中

### AC-4：查看結果快照（result）

- **Given** 業務主管點擊「結果快照」分頁
- **When** 分頁內容載入
- **Then** 顯示最終分派結果：總筆數、各部門分配量、各等級分佈
- **And** 提供搜尋功能，可依客戶編號或人員工號查詢分派記錄

---

## 技術備註

- 快照資料來源：AssignmentRunSnapshot 表（三筆 snapshot_type 分別為 'config'、'input_list'、'result'）
- JSONB payload 在前端解析並以表格方式呈現，不需要後端額外轉換
- 輸入名單與結果快照的搜尋功能在前端對 JSONB payload 進行過濾（資料量若超過 100,000 筆考慮後端搜尋 API）
- 快照資料為不可修改的唯讀記錄

---

## 測試案例

### TC-086-01：三份快照分頁顯示

- **Given**：run_id 'abc-123' 有三份快照
- **When**：業務主管進入詳情頁
- **Then**：顯示三個分頁索引，各分頁內容正常載入

### TC-086-02：設定快照正確性

- **Given**：config 快照記錄計分版本 v2，CR 回分為啟用
- **When**：查看設定快照分頁
- **Then**：顯示版本 v2 與 CR 回分啟用狀態

### TC-086-03：結果快照搜尋

- **Given**：結果快照含 9,500 筆
- **When**：業務主管搜尋客戶編號 'C001'
- **Then**：篩選顯示 C001 的分派記錄（部門、人員、等級）
