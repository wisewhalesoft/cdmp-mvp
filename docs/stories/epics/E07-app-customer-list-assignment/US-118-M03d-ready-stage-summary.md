# US-118：準備完成階段查詢摘要（唯讀）

> **Story ID**：US-118
> **Epic**：[E07 — 客戶名單分派](epic-brief.md)
> **模組**：M03d 準備完成階段
> **優先級**：Must Have
> **階段**：Phase 1（MVP）
> **預估點數**：5

---

## User Story

**As a** 部長（Director）、處長（Section Chief）或 Admin
**I want** 在名單進入「準備完成」階段後，查看該名單的完整設定摘要（篩選條件 + 部門比例 + 個別業務比例 + CR 開關），確認所有設定正確無誤
**So that** 月名單分派前可做最終確認，避免帶著錯誤設定進入月名單分派；部長也能在此頁面確認所有名單均已就緒後觸發月名單分派

---

## 背景說明

本 Story 是五階段流程（US-105）第五階段「準備完成（Stage 5 / `ready`）」的查詢功能。

**設計要點**：
- 本頁面為**完全唯讀**：所有設定欄位均僅供查看，無任何編輯按鈕
- 顯示範圍：篩選條件 JSONB（展開顯示）、部門比例表、個別業務比例表（按部門分組）、CR 回分開關狀態
- 處長可見範圍：**僅顯示本處長轄區**（依 `created_by` 過濾）的準備完成名單
- 部長 / Admin：可查看所有準備完成名單的完整摘要
- **月名單分派前置條件連結**：此頁面為部長確認「所有 active 名單均已就緒」的核心入口（US-081 AC-1 前置條件 1）

**與 US-078 的關係**：
- US-078 為「流程外的人員比例查詢入口」，不限階段
- 本 Story（US-118）為「準備完成階段的完整摘要查詢」，範圍更廣（含篩選條件、部門比例、CR 開關）

---

## 驗收標準

### AC-1：準備完成名單清單頁

- **Given** 部長 / Admin 進入 M01 五階段總覽（US-105）
- **When** 篩選顯示 stage = 'ready' 的名單，或點擊「準備完成」頁籤
- **Then** 顯示所有 ready 狀態的名單清單（LIST_NO / LIST_NM / 最後更新時間 / 核准者帳號 ID）
- **And** 處長進入相同頁面時，**僅顯示本轄區**（`created_by` = 本帳號 ID）的 ready 名單

### AC-2：查看單一名單完整設定摘要

- **Given** 部長 / 處長 / Admin 在 ready 名單清單點擊某名單
- **When** 進入名單詳情頁
- **Then** 顯示以下四個區塊的完整摘要（均為唯讀）：
  1. **篩選條件**：展開顯示所有篩選欄位及其條件值（JSONB 轉換為可讀格式）
  2. **部門比例**：各部門 DEPT_NAME + RATION（%）表格，底部顯示加總（應 = 100%）
  3. **個別業務比例**：按部門分組，各業務員 EMP_NM + RATION（%），各部門底部顯示加總
  4. **CR 回分開關**：顯示「啟用 / 停用」狀態
- **And** 頁面無任何「編輯」「修改」「儲存」等可操作按鈕或控件

### AC-3：處長僅可查看本轄區摘要

- **Given** 帳號持有「處長」角色
- **When** 查看 ready 名單清單或詳情頁
- **Then** 個別業務比例區塊**僅顯示本處長轄區的部門業務員資料**（其他部門的業務員不顯示）
- **And** 篩選條件、部門比例、CR 開關可查看（全名單共用，非按轄區過濾）

### AC-4：確認所有名單均已就緒（月名單分派前提示）

- **Given** 部長在 ready 名單清單頁
- **When** 頁面載入
- **Then** 若本月所有 active 名單（非停用、非草稿）均已進入 ready 狀態，頁面頂部顯示「所有名單已就緒，可觸發月名單分派」提示（綠色）
- **And** 若仍有名單未達 ready，頁面頂部顯示「以下名單尚未就緒：{LIST_NM_1}（{階段}）…，請確認後再觸發月名單分派」提示（警告色）
- **And** 此提示提供跳轉至對應名單的快速連結

### AC-5：唯讀保護（後端守衛）

- **Given** 名單 `stage = 'ready'`
- **When** 任何使用者透過 API 嘗試修改篩選條件 / 部門比例 / 個別業務比例 / CR 開關
- **Then** 後端回 422（「準備完成階段的名單設定為唯讀，如需修改請先 Rollback 至簽核」）

---

## 技術備註

- 查詢來源：
  - 篩選條件：`ob_list_definition.filter_conditions`（JSONB）
  - 部門比例：`ob_dept_pct` WHERE `list_no = {LIST_NO}`
  - 個別業務比例：`ob_empl_set` WHERE `list_no = {LIST_NO}`，JOIN `ob_emphire` 取 EMP_NM
  - CR 開關：`ob_list_definition.cr_enabled`（參見 US-120 定義的儲存位置）
- 處長轄區過濾：查詢 `ob_empl_set.created_by` = 處長帳號 ID，取對應 DEPT_CODE，再過濾個別業務比例顯示
- **月名單分派前置條件連結**：US-081 AC-1 前置條件 1 依賴本頁面狀態（所有 active 名單為 ready）
- **[通知 spec-writer]**：建議本 Story 搭配一個新的 API 端點：`GET /api/v1/list-definitions/ready-summary?ym={YYYYMM}`，回傳 ready 清單及各名單摘要

## 測試案例

### TC-118-01：部長查看 ready 名單完整摘要

- **Given**：LIST_NO = 'OB202506001'，stage = 'ready'；設定如下：PROD_KIND IN ['01','02']、部門 XTC0 30% / XTD0 70%、EMP001 60% / EMP002 40%（XTC0）、EMP003 100%（XTD0）、CR 開關=啟用；部長帳號
- **When**：部長點擊名單進入詳情頁
- **Then**：四個區塊均正確顯示，頁面無任何編輯按鈕

### TC-118-02：處長查看 ready 名單（個別業務比例限轄區）

- **Given**：LIST_NO = 'OB202506001'，stage = 'ready'；處長 A（轄區 XTC0）
- **When**：處長 A 進入名單詳情頁
- **Then**：個別業務比例區塊僅顯示 XTC0（EMP001/EMP002），不顯示 XTD0（EMP003）；篩選條件、部門比例、CR 開關均顯示完整

### TC-118-03：所有名單就緒時顯示可月名單分派提示

- **Given**：本月有 3 份 active 名單，均為 ready 狀態；部長帳號
- **When**：部長進入 ready 名單清單頁
- **Then**：頁面頂部顯示「所有名單已就緒，可觸發月名單分派」（綠色提示）

### TC-118-04：有名單未就緒時顯示警告提示

- **Given**：本月有 3 份 active 名單，2 份 ready、1 份仍在 dept_ratio 階段；部長帳號
- **When**：部長進入 ready 名單清單頁
- **Then**：頁面頂部顯示「以下名單尚未就緒：{LIST_NM_X}（部門比例設定）」警告提示，含跳轉連結

### TC-118-05：嘗試 API 修改 ready 名單被拒

- **Given**：LIST_NO = 'OB202506001'，stage = 'ready'
- **When**：部長嘗試呼叫修改篩選條件 API
- **Then**：後端回 422「準備完成階段的名單設定為唯讀，如需修改請先 Rollback 至簽核」
