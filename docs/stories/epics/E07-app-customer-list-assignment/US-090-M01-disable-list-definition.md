## User Story

**As a** 部長（Director）或 Admin
**I want** 在草稿階段停用不再需要的名單定義
**So that** 避免已過時或錯誤設定的名單條件在月跑中被誤用，同時保留歷史記錄以供查閱；非草稿階段的名單以「退回上一階段」機制處理，不提供直接停用

---

## 背景說明

本次重構後，名單定義流程分為五個階段（US-105）：

1. **草稿（Draft）** — 名單可編輯；**唯一可停用的階段**
2. 部門比例設定階段
3. 個別業務比例設定階段
4. 簽核階段
5. 準備完成階段

**停用規則**（2026-05-15 確認）：
- **停用入口僅在草稿階段**：名單只有在草稿階段才顯示「停用」按鈕
- **非草稿階段**：不提供「停用」按鈕；若名單需退回或取消，以「退回上一階段」機制（Rollback，US-C 組規劃）處理
- **Actor**：停用操作限 **部長 + Admin**；處長無法停用名單定義

**月跑執行中的鎖定**：月跑進行中（AssignmentRun status = 'running'）時，禁止停用操作。

## 驗收標準

### AC-1：草稿階段名單顯示「停用」按鈕（部長 / Admin 限定）

- **Given** 部長或 Admin 在名單定義清單（US-070）或五階段總覽（US-105）查看某個**草稿階段**的名單
- **When** 頁面顯示該名單列表項
- **Then** 顯示「停用」按鈕（或操作選項）
- **And** 處長帳號進入相同頁面時，**不顯示「停用」按鈕**（即使名單在草稿階段）

### AC-2：停用確認對話框

- **Given** 部長或 Admin 點擊草稿階段名單的「停用」按鈕
- **When** 系統彈出確認對話框
- **Then** 對話框顯示警告文字：「確定停用名單『{LIST_NM}』（{LIST_NO}）？停用後此名單將不再用於月跑，且無法在本系統重新啟用。歷史快照資料不受影響。」
- **And** 對話框提供「確認停用」與「取消」兩個按鈕

### AC-3：執行停用（軟刪除）

- **Given** 部長或 Admin 在確認對話框點擊「確認停用」
- **When** 後端處理停用請求
- **Then** 系統將名單定義狀態更新為「已停用（disabled）」
- **And** 名單退出五階段流程，不再參與月跑分派計算
- **And** audit 欄位（U_* 修改者與修改時間）由後端自動更新
- **And** 操作寫入 AssignmentAuditLog（action = 'DISABLE'，含 LIST_NO、操作者帳號 ID、時間）
- **And** 頁面顯示成功提示：「名單『{LIST_NM}』已停用」，清單刷新

### AC-4：非草稿階段名單不顯示「停用」入口

- **Given** 名單定義目前處於草稿以外的任一階段（部門比例設定 / 個別業務比例設定 / 簽核 / 準備完成）
- **When** 部長或 Admin 在清單或詳情頁查看該名單
- **Then** **不顯示「停用」按鈕**
- **And** 若需退出流程，引導使用「退回上一階段」機制（非本 Story 範圍，由 Rollback Story 定義）
- **And** 若透過 API 直接嘗試停用非草稿階段名單，後端回 422（「只有草稿階段名單可停用」）

### AC-5：處長帳號無停用權限

- **Given** 帳號持有「處長」角色（非部長、非 Admin）
- **When** 查看任意階段的名單定義清單頁
- **Then** 所有名單均**不顯示「停用」按鈕**
- **And** 若處長直接呼叫停用 API，後端回 403 Forbidden

### AC-6：停用後可從「已停用」頁籤查閱

- **Given** 名單 STATUS 已更新為「已停用」
- **When** 業務主管切換至「已停用」頁籤
- **Then** 該名單出現在「已停用」頁籤中，可展開查看所有欄位值（唯讀）
- **And** 「已停用」頁籤不顯示「編輯」或「停用」按鈕，僅供查閱

### AC-7：不提供重新啟用（MVP 範圍）

- **Given** 名單 STATUS = 已停用
- **When** 部長或 Admin 在「已停用」頁籤查看該名單
- **Then** 不顯示任何「啟用」、「重新啟用」或「恢復」按鈕
- **And** 若需恢復使用相同條件，部長或 Admin 可透過「建立名單」（US-106）新建草稿

### AC-8：月跑執行中禁止停用

- **Given** 目前有 AssignmentRun status = 'running' 的月跑
- **When** 部長或 Admin 嘗試點擊任何名單的「停用」按鈕
- **Then** 停用按鈕為停用狀態，hover 顯示提示「分派執行中，無法停用名單定義」

### AC-8b：非草稿階段嘗試停用時提示 Rollback 路徑（OQ-C-02 衍生）

- **Given** 部長或 Admin 嘗試透過 API 停用一份**非草稿**階段的名單（例如：部門比例設定階段 / 個別業務比例設定階段 / 簽核階段 / 準備完成階段）
- **When** 後端收到停用請求
- **Then** 後端回 422（error_code: `LIST_DISABLE_REQUIRES_DRAFT_STAGE`），並在 message 中說明：「只有草稿階段名單可停用。如需退出流程，請先依 Rollback 路徑逐步退回草稿（準備完成 → 簽核 → 個別業務比例 → 部門比例 → 草稿），再執行停用。」
- **And** 前端若偵測到非草稿狀態，在停用操作入口旁顯示提示文字：「此名單尚在 [當前階段]，請先 Rollback 至草稿後再停用」
- **And** 系統不執行任何停用操作

> **[通知 spec-writer]**：此 AC 對應 OQ-C-02 確認的五階段 Rollback 規則，Rollback Story 群組為 US-111（部門比例 → 草稿）、US-115（個別業務比例 → 部門比例）、US-119（準備完成 → 簽核）及 US-117（拒絕 = 簽核 → 個別業務比例）。

### AC-9：已被 completed 月跑使用過的草稿名單可停用

- **Given** 某草稿階段名單曾被歷史 completed 月跑使用（快照中有記錄）
- **When** 部長或 Admin 執行停用
- **Then** 系統允許停用，STATUS 更新為「已停用」
- **And** 歷史快照中對該名單的參照保持完整，不受停用影響

## 技術備註

- 停用為軟刪除：僅更新名單狀態，不刪除資料列
- **「草稿階段」判斷**：後端在執行停用前先查詢名單目前的五階段狀態，若非草稿則回 422；前端在呈現按鈕時也依五階段狀態決定是否顯示
- **[通知 spec-writer]**：停用條件「僅草稿可停用」需在 F059（或對應的月跑流程 spec）中明確標記，避免月跑階段引用該名單時出現狀態衝突
- **不提供重新啟用**：MVP 範圍決策，避免業務邏輯複雜化；若業務需求升級可列入 Phase 2
- AssignmentAuditLog 寫入：action = 'DISABLE'（表結構由 system-architect 設計，已在 epic-brief 中確認）
- 月跑中資料鎖判斷：查詢 AssignmentRun 是否有 status = 'running' 記錄
- 停用後對未來月跑的影響：月跑 Stage 0/1 只讀取非已停用狀態的名單，已停用名單不參與未來分派計算
- 歷史快照記錄的是月跑當時的篩選結果，不受名單狀態變更影響

## 測試案例

### TC-090-01：草稿階段名單正常停用（部長）

- **Given**：LIST_NO = 'OB202605001'，狀態 = 草稿，LIST_NM = 「車貸月跑名單」；部長帳號
- **When**：部長點擊「停用」→ 確認對話框 → 點擊「確認停用」
- **Then**：名單狀態更新為「已停用」；AssignmentAuditLog 新增 action = 'DISABLE' 記錄；清單移至「已停用」頁籤

### TC-090-02：非草稿階段名單無停用按鈕

- **Given**：LIST_NO = 'OB202605002'，狀態 = 「部門比例設定階段」；部長帳號
- **When**：部長在清單頁查看該名單
- **Then**：不顯示「停用」按鈕；API 直接停用回 422

### TC-090-03：處長嘗試停用草稿階段名單被拒

- **Given**：LIST_NO = 'OB202605001'，狀態 = 草稿；帳號持有「處長」角色
- **When**：處長嘗試呼叫停用 API
- **Then**：後端回 403 Forbidden；清單頁不顯示該名單的停用按鈕

### TC-090-04：停用後唯讀查閱

- **Given**：LIST_NO = 'OB202605001'，狀態 = 已停用
- **When**：部長在「已停用」頁籤展開該名單
- **Then**：顯示全部欄位值，不顯示「編輯」或「停用」或「啟用」按鈕

### TC-090-05：月跑中禁止停用

- **Given**：AssignmentRun status = 'running'
- **When**：部長嘗試點擊草稿名單的「停用」按鈕
- **Then**：按鈕停用，顯示「分派執行中，無法停用名單定義」提示
