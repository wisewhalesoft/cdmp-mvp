# US-105：名單五階段狀態總覽

> **Story ID**：US-105
> **Epic**：[E07 — 客戶名單分派](epic-brief.md)
> **模組**：M01 名單定義
> **優先級**：Must Have
> **階段**：Phase 1（MVP）
> **預估點數**：5

---

## User Story

**As a** 部長（Director）或 Admin 或 處長（Section Chief）
**I want** 在名單定義清單頁看到每份名單目前所在的五階段狀態，並能依階段篩選名單列表
**So that** 快速掌握每份名單的流程進度，識別尚未完成設定或等待確認的名單，減少遺漏

---

## 背景說明

E07 名單分派流程分為五個明確階段，每份名單定義（LIST_NO）在任一時點必定處於其中一個階段：

| 階段編號 | 階段名稱 | 說明 |
|---------|---------|------|
| Stage 1 | 草稿（Draft） | 名單剛建立，篩選條件可編輯；名單尚未推進至任何設定階段 |
| Stage 2 | 部門比例設定（Department Ratio） | 名單已推進；部長 / Admin 設定各部門分派比例 |
| Stage 3 | 個別業務比例設定（Personnel Ratio） | 部門比例設定完成；處長設定轄區各業務員比例 |
| Stage 4 | 簽核（Approval） | 個別比例設定完成；等待部長 / Admin 核准 |
| Stage 5 | 準備完成（Ready） | 簽核完成；名單準備好進入月跑 |

此外，名單可被「停用（Disabled）」，退出五階段流程，不再參與月跑。

## 驗收標準

### AC-1：清單頁顯示每份名單的當前階段

- **Given** 部長、Admin 或處長進入 M01 名單定義清單頁（US-070）
- **When** 頁面載入（依目前作業月份，或依 US-104 月份切換選定的月份）
- **Then** 清單每列顯示 LIST_NO、LIST_NM、當前階段名稱（如「草稿」「部門比例設定」）、最後更新時間
- **And** 階段以視覺標籤（Tag / Badge）區分，不同階段使用不同顏色（例如：草稿＝灰色、準備完成＝綠色）
- **And** 「已停用」名單獨立於五階段流程之外，以「已停用」標籤區分

### AC-2：依階段篩選名單列表

- **Given** 使用者在清單頁看到多份不同階段的名單
- **When** 使用者點擊階段篩選器，選取「草稿」或「部門比例設定」等特定階段
- **Then** 列表僅顯示符合選取階段的名單，其他階段名單不顯示
- **And** 可多選階段進行複合篩選（例如同時顯示「草稿」+「簽核」階段名單）
- **And** 清除篩選後恢復顯示所有名單（含停用除外的各階段）

### AC-3：已停用名單的顯示規則

- **Given** 清單頁顯示當前作業月份的名單
- **When** 頁面載入
- **Then** 預設不顯示已停用名單（已停用名單隱藏於「已停用」頁籤或需透過篩選器顯示）
- **And** 使用者可明確選取「已停用」篩選項，查看本月份的已停用名單列表

### AC-4：處長的可見範圍限制在轄區，且不顯示 M02 導覽連結

- **Given** 帳號持有「處長」角色
- **When** 進入清單頁
- **Then** 僅顯示本處長轄區（依 `created_by` 過濾）的名單
- **And** 其他處長轄區的名單不顯示
- **And** 頁面（包含頂部 Tab 與側邊 Nav）**不顯示 M02 計分設定的任何入口連結**（OQ-C-03 決議：M02 對處長完全隱藏）

### AC-5：各角色可見操作按鈕依階段與角色決定

- **Given** 使用者在清單頁查看名單列表
- **When** 頁面顯示各名單的操作欄
- **Then** 各名單顯示的操作按鈕依「目前階段」+「使用者角色」決定：
  - 草稿階段 + 部長 / Admin：顯示「停用」「推進至部門比例設定」
  - 草稿階段 + 處長：不顯示任何操作按鈕（草稿階段處長無操作權限）
  - 個別業務比例設定階段 + 處長：顯示「設定個別比例」按鈕（限轄區）
  - 準備完成階段 + 任意角色：無可操作按鈕（唯讀）

### AC-6：階段狀態顯示支援歷史月份

- **Given** 使用者透過 US-104 月份切換至歷史月份
- **When** 清單頁顯示歷史月份名單
- **Then** 顯示歷史月份各名單在**當時**最終達到的階段狀態
- **And** 歷史月份所有操作按鈕均不顯示（唯讀）

---

## 技術備註

- 「階段」欄位建議在 `ob_list_definition` 表新增 `stage` 欄位（ENUM 或 VARCHAR），由各流程操作（推進 / 退回 / 停用）更新；具體 schema 由 system-architect 決策
- 預設狀態：名單建立時 `stage = 'draft'`
- 「準備完成」（stage = 'ready'）表示已可進入月跑；月跑 Stage 0/1 只讀取 stage = 'ready' 的名單
- 篩選器實作建議：前端依 stage 欄位過濾，支援 multi-select；後端 API 加 `?stage=draft,approval` query param

## 測試案例

### TC-105-01：清單頁顯示各名單的階段標籤

- **Given**：本月份有 5 份名單：2 草稿、1 部門比例設定、1 個別比例設定、1 準備完成
- **When**：部長進入 M01 清單頁
- **Then**：5 份名單均顯示，各自的階段標籤正確（草稿 x2、部門比例設定 x1、個別比例設定 x1、準備完成 x1）

### TC-105-02：篩選器選取「草稿」後只顯示草稿名單

- **Given**：本月份有 5 份名單（同上）
- **When**：部長點擊篩選器，選取「草稿」
- **Then**：清單只顯示 2 份草稿名單

### TC-105-03：多選篩選器組合

- **Given**：本月份有 5 份名單
- **When**：部長同時選取「草稿」+「準備完成」
- **Then**：清單顯示 3 份名單（草稿 2 + 準備完成 1）

### TC-105-04：處長只看到轄區名單

- **Given**：本月份共 5 份名單，其中 2 份屬處長 A 轄區；3 份屬其他處長
- **When**：處長 A 進入清單頁
- **Then**：只顯示 2 份屬其轄區的名單

### TC-105-05：歷史月份名單顯示當時最終階段且唯讀

- **Given**：202504 月份有 3 份名單，最終狀態分別為「準備完成 x2 + 停用 x1」
- **When**：部長透過月份切換器選取 202504
- **Then**：清單顯示 3 份名單含各自的最終階段標籤；所有操作按鈕不顯示；頁面顯示「歷史月份唯讀」提示
