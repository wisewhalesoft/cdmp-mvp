# US-068：Customer 360 角色存取設定

> **Story ID**：US-068
> **Epic**：[E06 — Customer 360](epic-brief.md)
> **優先級**：Could Have
> **階段**：Phase 2（原 Phase 3，2026-04-02 合併至 Phase 2）
> **預估點數**：8

---

## User Story

**As a** Admin（管理者）
**I want** 為 Customer 360 模組設定細粒度的角色存取權限，控制不同角色可以查看哪些客戶資料欄位分類、哪些欄位需要遮罩、以及可以使用哪些功能
**So that** 我能確保敏感客戶資料（如財務風控、聯絡資訊）只有具備業務必要性的角色才能完整存取，同時符合資料治理法規要求

---

## User Story（業務人員視角）

**As a** 業務（或行銷/企劃、客服、分析師、主管、後端作業/作服）
**I want** 以對應業務角色登入後，只看到與工作相關的客戶資料欄位，敏感資訊依角色設定自動遮罩或隱藏
**So that** 我能專注於業務工作所需資訊，同時避免接觸不必要的敏感資料

---

## 驗收標準

### AC-1：角色定義（已確認角色名稱）
- **Given** Admin 進入系統設定的「角色管理」頁面
- **When** 頁面載入完成
- **Then** 系統顯示預定義的 Customer 360 角色清單，共六種業務角色：
  - **業務**（無別名）
  - **行銷**（別名：企劃）
  - **客服**（無別名）
  - **分析師**（無別名）
  - **主管**（無別名）
  - **後端作業**（別名：作服）
  
  角色定義與使用者指派入口整合至 **E02 帳號管理模組**（US-014），本頁面僅顯示角色清單及其 Customer 360 存取設定，不提供角色 CRUD 功能

### AC-2：欄位分類存取控制設定
- **Given** Admin 在角色管理頁面選擇某業務角色（如「業務」或「分析師」）
- **When** Admin 進入該角色的 Customer 360 存取設定
- **Then** 系統顯示 customer_core 的 8 個欄位分類（A~H）的存取設定，每個分類可設定三個層級：
  - **完整顯示**：欄位原始值完整呈現
  - **遮罩顯示**：敏感欄位部分遮罩（如身分證 `A12****89`、電話 `0912**78`）
  - **隱藏**：整個分類不顯示（替換為「您沒有權限查看此資訊」提示）

### AC-3：角色存取設定套用
- **Given** Admin 已設定「業務」角色不可查看「F. 財務與風控」分類
- **When** 業務角色的使用者登入並進入客戶 360 頁面
- **Then** F. 財務與風控分類不顯示（替換為「您沒有權限查看此資訊」的佔位訊息）

### AC-4：聯絡資訊遮罩規則設定
- **Given** Admin 在角色存取設定中，為「C. 聯絡資訊」分類選擇「遮罩顯示」
- **When** 該角色的使用者進入客戶清單（US-060）或客戶 360 頁面（US-061）
- **Then** 聯絡資訊欄位依以下預設遮罩規則處理：
  - 電話號碼（`mobile_phone`、`home_phone`、`contact_phone`、`office_phone`）：顯示前 4 碼 + 末 2 碼，中間以 `*` 遮罩
  - 電子郵件（`email`）：顯示首字元 + `@domain`，帳號部分遮罩（如 `a****@example.com`）
  - `line_account`：整體遮罩，僅顯示「已設定」

### AC-5：功能層級存取控制
- **Given** Admin 設定「後端作業（作服）」角色不可使用標籤功能
- **When** 後端作業角色的使用者在客戶 360 頁面
- **Then** 標籤管理按鈕不顯示（或顯示為 disabled 狀態），無法為客戶新增/移除標籤

### AC-6：角色繼承 Admin 完整存取
- **Given** 使用者的角色為 Admin
- **When** Admin 進入 Customer 360 模組
- **Then** Admin 始終具備所有欄位分類與功能的完整存取權，不受角色設定影響

### AC-7：使用者角色指派整合 E02
- **Given** Admin 在 E02 帳號管理模組（US-014）為使用者指派六種業務角色之一（業務／行銷／客服／分析師／主管／後端作業）
- **When** 使用者登入後進入 Customer 360 模組
- **Then** 系統根據該使用者在 E02 被指派的業務角色，套用對應的 Customer 360 存取設定（欄位可見性、遮罩規則、功能開關）

### AC-8：設定變更即時生效
- **Given** Admin 修改某角色的欄位存取設定
- **When** 被指派該角色的使用者下次發出 API 請求（或重新載入頁面）
- **Then** 新的存取設定即時生效（不需要重新登入）

## Technical Notes

### 資料模型：c360_role_permissions

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | UUID (PK) | 主鍵 |
| role_name | VARCHAR(50) | 角色名稱（與帳號管理模組的角色系統整合） |
| feature | VARCHAR(50) | 功能模組（如 `customer_search`、`customer_360_view`、`tag_management`） |
| field_category | VARCHAR(2) | 欄位分類（A~H，NULL 表示功能層級設定）|
| access_level | ENUM('full', 'masked', 'hidden') | 存取層級 |
| updated_by | UUID (FK) | 最後修改者 |
| updated_at | TIMESTAMP | 最後修改時間 |

### 角色整合方案（已確認）

**整合原則**：六種業務角色（業務、行銷/企劃、客服、分析師、主管、後端作業/作服）的定義、建立與使用者指派，**整合至 E02 帳號管理模組（US-014）**，不在 E06 獨立管理。

**職責分工**：
- E02 帳號管理：角色 CRUD、使用者與角色的指派關係
- E06 US-068：各業務角色在 Customer 360 模組的欄位可見性、遮罩規則、功能開關設定

**Phase 2 角色基礎**：E02 在 Phase 1 已新增 US-017（業務角色定義），六種業務角色以系統預設 Seed Data 形式存在。US-068 在 Phase 2 直接依賴此基礎進行角色存取設定，不再需要額外的 E02 角色擴充 Story。

**E02 整合確認（2026-04-02）**：E02 Phase 1 已建立六種業務角色 Seed Data（US-017），E02 US-014 已支援指派六種業務角色。US-068 實作時可直接使用這些角色代碼（`business`、`marketing`、`customer_service`、`analyst`、`supervisor`、`backend_ops`）設定 `c360_role_permissions` 資料表。

### 敏感資料遮罩規則（統一定義）

本 Story 為所有 Customer 360 頁面的遮罩規則權威來源，US-060 及 US-061 的遮罩行為均由此處設定驅動：

| 欄位 | 完整顯示 | 遮罩顯示 | 隱藏 |
|------|---------|---------|------|
| `source_customer_no`（身分證/統編） | 原始值 | 首 1 碼 + 末 2 碼（如 `A12****89`） | 不顯示 |
| `mobile_phone` / `home_phone` / `contact_phone` / `office_phone` | 原始值 | 前 4 碼 + 末 2 碼（如 `0912**78`） | 不顯示 |
| `email` | 原始值 | 帳號部分遮罩（如 `a****@example.com`） | 不顯示 |
| `line_account` | 原始值 | 顯示「已設定」 | 不顯示 |
| `residential_address` / `mailing_address` 等 | 原始值 | 僅顯示縣市層級 | 不顯示 |

### API 端點（Admin 設定）

- 端點：`GET /api/v1/c360/role-permissions` — 查詢所有角色的存取設定
- 端點：`PUT /api/v1/c360/role-permissions/:roleName` — 更新指定角色的存取設定

## 測試案例

| # | 測試案例 | 預期結果 |
|---|---------|---------|
| 1 | Admin 進入角色管理，檢視角色清單 | 顯示六種業務角色：業務、行銷（企劃）、客服、分析師、主管、後端作業（作服） |
| 2 | Admin 選擇「業務」角色，進入 Customer 360 存取設定 | 顯示 A~H 共 8 個欄位分類的存取設定（完整顯示／遮罩顯示／隱藏） |
| 3 | Admin 設定「業務」角色不可查看 F 分類 | 業務角色使用者登入後 F 分類顯示「您沒有權限查看此資訊」 |
| 4 | Admin 設定「行銷（企劃）」角色無標籤管理權限 | 行銷角色使用者看不到「管理標籤」按鈕 |
| 5 | Admin 設定「客服」角色 C 聯絡資訊為「遮罩顯示」 | 客服角色使用者在客戶 360 頁面看到電話號碼格式為 `0912**78` |
| 6 | Admin 自身存取所有分類 | Admin 始終可查看全部 8 個分類完整資料 |
| 7 | Admin 變更「分析師」角色設定後，分析師使用者重新整理頁面 | 新設定即時生效 |
| 8 | 後端作業（作服）角色使用者嘗試新增客戶標籤 | 標籤功能按鈕不顯示，操作被阻擋 |
| 9 | 未登入使用者存取客戶 360 API | 回傳 401 Unauthorized |
