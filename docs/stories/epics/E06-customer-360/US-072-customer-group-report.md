# US-072：客戶群組統計報表

> **Story ID**：US-072
> **Epic**：[E06 — Customer 360](epic-brief.md)
> **優先級**：Could Have
> **階段**：Phase 2
> **預估點數**：8
> **變更說明（2026-04-07）**：AC-2 明確統計範圍僅含全域標籤；Technical Notes 補充效能目標（≤10 標籤 < 3 秒；> 10 標籤 < 10 秒）；`updatedAt` 語意說明

---

## User Story

**As a** 主管或分析師
**I want** 以標籤群組或篩選條件為維度，產出客戶群組的統計報表
**So that** 我能從「看個別客戶」升級到「看客戶群組趨勢」，掌握不同族群的財務指標分佈與地區分佈，支援業務策略決策

---

## 驗收標準

### AC-1：進入群組統計報表頁面
- **Given** 使用者角色為主管或分析師，並已登入系統
- **When** 使用者在 Customer 360 模組導覽至「群組統計報表」
- **Then** 頁面顯示報表維度選擇器，預設維度為「依標籤分組」，並顯示目前所有標籤的群組統計摘要

### AC-2：依標籤分組統計（僅含全域標籤）
- **Given** 使用者選擇「依標籤分組」維度
- **When** 頁面載入完成
- **Then** 報表以每個**全域標籤（tag_type = 'global'）**為一列，顯示以下統計指標：
  - 標籤名稱
  - 客戶數（該全域標籤下的客戶總數）
  - 平均財務指標（如平均授信額度、平均存款餘額等，依 customer_core 可用欄位決定）
  - 地區分佈（前三大地區及其佔比，以文字形式顯示）
  - 最後更新時間
  
  **統計範圍說明**：「依標籤分組」**僅統計全域標籤（Global Tag）**，不含自訂標籤（Custom Tag）。自訂標籤為個人工作標記，僅建立者可見，不適合作為群組統計維度。

### AC-3：依篩選條件分組統計
- **Given** 使用者在客戶清單頁面（US-060）套用了篩選條件（如客戶類型、地區、標籤組合）
- **When** 使用者點擊「產出統計報表」按鈕
- **Then** 系統以當前篩選條件為範圍，產出該群組的統計報表，頁面標題顯示「自訂篩選群組統計」，並說明當前篩選條件組合

### AC-4：財務指標分佈統計
- **Given** 使用者查看特定標籤或篩選群組的統計報表
- **When** 使用者選擇「財務指標分佈」頁籤
- **Then** 報表顯示該群組內客戶的財務指標分佈，包含：最大值、最小值、平均值、中位數（以文字數字形式呈現，不要求圖表）

### AC-5：地區分佈統計
- **Given** 使用者查看特定群組的統計報表
- **When** 使用者選擇「地區分佈」頁籤
- **Then** 報表以地區（縣市）為維度，顯示各地區的客戶數及佔比（%），以清單形式排列，按客戶數降序

### AC-6：角色存取控制
- **Given** 登入者角色非主管或分析師（如業務、客服、行銷、後端作業）
- **When** 使用者嘗試進入群組統計報表頁面
- **Then** 系統不顯示該導覽項目；若直接透過 URL 存取，API 回傳 403

### AC-7：空白群組處理
- **Given** 使用者選擇的標籤下無任何客戶，或篩選條件結果為零筆
- **When** 報表產出
- **Then** 報表顯示「此群組目前無客戶資料」的空白狀態提示，不顯示錯誤訊息

---

## Technical Notes

- 統計資料來源為 `customer_core` 目標表，報表為即時查詢（非預先快取）
- 財務指標欄位由 `customer_core` Schema 決定，Phase 2 暫定以授信額度（credit_limit）與存款餘額（deposit_balance）為主，實際欄位依 E05 US-049 的 customer_core 定義為準
- 地區分佈以 `customer_core` 中的縣市欄位（city / region）為維度分組
- **統計範圍**：「依標籤分組」僅統計全域標籤（`tag_type = 'global'`），不含自訂標籤（`tag_type = 'custom'`）
- **`updatedAt` 語意**：API Response 中的 `updatedAt` 代表 `customer_core` 目標表中，該群組客戶的最後 ETL 更新時間（即 `MAX(_etl_loaded_at)`），不代表統計查詢的執行時間
- **效能目標（2026-04-07 業務確認）**：
  - 群組統計查詢（全域標籤數量 ≤ 10 個）：回應時間 < 3 秒
  - 群組統計查詢（全域標籤數量 > 10 個）：回應時間 < 10 秒
  - 超過 10 個全域標籤時，建議後端分批查詢或加入統計快取機制（Phase 3 可加強）
- 角色控制由後端 API 依角色過濾，不在前端硬編碼；允許的角色為主管（supervisor）與分析師（analyst）

### API 端點

**取得標籤群組統計**

- 端點：`GET /api/v1/c360/reports/group-stats?dimension=tag`
- Query 參數：
  - `dimension`：`tag`（依標籤）或 `filter`（依篩選條件）
  - `keyword`、`type`、`tagId` 等（同客戶清單 API，用於自訂篩選群組）
- Response：
```json
{
  "dimension": "tag",
  "groups": [
    {
      "groupKey": "tag-uuid",
      "groupLabel": "VIP",
      "customerCount": 120,
      "financialStats": {
        "creditLimitAvg": 5000000,
        "creditLimitMax": 20000000,
        "creditLimitMin": 100000,
        "creditLimitMedian": 3000000
      },
      "regionDistribution": [
        { "region": "台北市", "count": 45, "ratio": 0.375 },
        { "region": "新北市", "count": 30, "ratio": 0.25 },
        { "region": "其他", "count": 45, "ratio": 0.375 }
      ],
      "updatedAt": "ISO8601"
    }
  ],
  "generatedAt": "ISO8601"
}
```

## 測試案例

| # | 測試案例 | 預期結果 |
|---|---------|---------|
| 1 | 主管進入群組統計報表頁面 | 顯示所有標籤的群組統計摘要 |
| 2 | 分析師進入群組統計報表頁面 | 顯示所有標籤的群組統計摘要 |
| 3 | 業務角色嘗試進入群組統計報表 | 導覽中不顯示入口；直接 URL 存取 API 回傳 403 |
| 4 | 查看「VIP」標籤的財務指標分佈 | 顯示授信額度的最大值、最小值、平均值、中位數 |
| 5 | 查看地區分佈 | 以縣市為維度，按客戶數降序顯示各地區佔比 |
| 6 | 篩選條件結果為 0 筆，產出統計報表 | 顯示「此群組目前無客戶資料」空白狀態，不報錯 |
| 7 | 在客戶清單套用複合篩選後點擊「產出統計報表」 | 報表以該篩選結果為範圍，標題說明篩選條件 |
| 8 | 未登入呼叫報表 API | 回傳 401 |
