# US-071：客戶互動紀錄

> **Story ID**：US-071
> **Epic**：[E06 — Customer 360](epic-brief.md)
> **優先級**：Should Have
> **階段**：Phase 2
> **預估點數**：8
> **可見範圍確認（2026-04-03）**：業務/客服僅能查看本人建立的互動紀錄；主管可查看所有使用者的紀錄（已確認）
> **變更說明（2026-04-07）**：AC-7 補充 Phase 2 主管查看全系統紀錄的說明；部門隔離機制列為 Phase 3 待評估

---

## User Story

**As a** 業務或客服人員
**I want** 在客戶 360 頁面為個別客戶新增結構化的互動紀錄，並查看該客戶的互動歷程
**So that** 我和主管能追蹤與客戶的往來記錄，確保服務品質與後續跟進不遺漏

---

## 驗收標準

### AC-1：互動紀錄區段顯示
- **Given** 使用者進入客戶 360 檢視頁面（US-061），且使用者角色為業務、客服、或主管
- **When** 頁面載入完成
- **Then** 頁面新增「互動紀錄」區段，顯示該客戶的互動紀錄列表（按建立時間倒序排列），並提供「新增互動紀錄」按鈕

### AC-2：新增互動紀錄
- **Given** 使用者點擊「新增互動紀錄」按鈕
- **When** 表單 Dialog 開啟
- **Then** 表單包含以下必填/選填欄位：
  - **互動類型**（必填）：下拉選單，選項為「電話」、「Email」、「面訪」、「投訴」、「跟進」、「其他」
  - **日期時間**（必填）：日期時間選擇器，預設為當前時間
  - **摘要**（必填）：文字輸入欄位，最多 500 字
  - **處理結果**（選填）：文字輸入欄位，最多 200 字

### AC-3：儲存互動紀錄
- **Given** 使用者填寫完互動紀錄表單，所有必填欄位均已填寫
- **When** 使用者點擊「儲存」按鈕
- **Then** 系統建立互動紀錄，自動記錄「記錄人」（當前登入者的帳號 ID 與姓名）及「建立時間」（系統時間 UTC），顯示成功通知「互動紀錄已新增」，互動紀錄列表即時更新並將新紀錄顯示於最頂部

### AC-4：表單必填驗證
- **Given** 使用者未填寫必填欄位（互動類型或日期時間或摘要）
- **When** 使用者點擊「儲存」按鈕
- **Then** 系統顯示欄位層級的錯誤提示（如「請選擇互動類型」），不送出 API 請求

### AC-5：互動紀錄列表顯示
- **Given** 該客戶有至少一筆互動紀錄
- **When** 互動紀錄區段載入完成
- **Then** 每筆紀錄顯示：互動類型 Badge（以不同色彩區分類型）、日期時間、摘要（超過 100 字時截斷並顯示「展開」）、處理結果（若有）、記錄人姓名、建立時間

### AC-6：業務/客服的紀錄可見範圍
- **Given** 登入者角色為業務或客服
- **When** 查看互動紀錄列表
- **Then** 僅顯示該登入者本人建立的互動紀錄

### AC-7：主管的紀錄可見範圍
- **Given** 登入者角色為主管
- **When** 查看互動紀錄列表
- **Then** 顯示該客戶**全系統所有使用者**建立的互動紀錄，每筆紀錄標示記錄人姓名
- **Phase 2 範圍**：主管可查看全系統（跨部門）所有使用者針對該客戶的互動紀錄；**部門隔離機制**（如主管僅能查看同部門人員的紀錄）列為 Phase 3 待評估，不在 Phase 2 範圍內

### AC-8：編輯互動紀錄（限建立者本人，限 24 小時內）
- **Given** 登入者為該互動紀錄的建立者，且紀錄建立時間在 24 小時以內
- **When** 使用者點擊紀錄列的「編輯」按鈕
- **Then** 開啟編輯表單，顯示現有資料，使用者可修改「互動類型」、「日期時間」、「摘要」、「處理結果」後儲存；儲存成功顯示「互動紀錄已更新」

### AC-9：超過 24 小時不可編輯
- **Given** 互動紀錄建立時間超過 24 小時
- **When** 使用者查看該紀錄
- **Then** 不顯示「編輯」按鈕，紀錄呈唯讀狀態

### AC-10：互動紀錄不可刪除
- **Given** 任何角色的使用者（含主管）查看互動紀錄
- **When** 查看互動紀錄列表
- **Then** 不提供「刪除」按鈕或刪除入口（稽核需求，所有紀錄永久保存）

### AC-11：後端作業角色不顯示互動紀錄功能
- **Given** 登入者角色為後端作業（作服）
- **When** 進入客戶 360 頁面
- **Then** 頁面不顯示「互動紀錄」區段（後端作業角色僅需覆核客戶基本資料與財務欄位，不需記錄互動）

## Technical Notes

- 新增資料表：`customer_interactions`
  - `id`：UUID (PK)
  - `customer_id`：UUID (FK → customer_core.customer_id)
  - `interaction_type`：ENUM（'phone'、'email'、'visit'、'complaint'、'followup'、'other'）
  - `interaction_at`：TIMESTAMP（互動發生的日期時間，使用者填寫）
  - `summary`：VARCHAR(500)（摘要）
  - `outcome`：VARCHAR(200) NULLABLE（處理結果）
  - `created_by`：UUID (FK → accounts.id)（記錄人）
  - `created_at`：TIMESTAMP（系統建立時間 UTC）
  - `updated_at`：TIMESTAMP（最後更新時間 UTC）
  - 無 `deleted_at`（不支援軟刪除，稽核需求）
- 可見範圍控制由後端 API 依角色過濾，不在前端硬編碼
- 編輯權限在後端驗證：`created_by = currentUserId` 且 `created_at > NOW() - INTERVAL '24 hours'`
- 索引建議：`customer_id` + `created_at DESC`（複合索引，用於分頁查詢）

### API 端點

**查詢互動紀錄列表**

- 端點：`GET /api/v1/c360/customers/:customerId/interactions?page=1&pageSize=20`
- Response：
```json
{
  "data": [
    {
      "id": "uuid",
      "interactionType": "phone",
      "interactionTypeLabel": "電話",
      "interactionAt": "ISO8601",
      "summary": "說明內容",
      "outcome": "處理結果",
      "createdBy": {
        "id": "uuid",
        "displayName": "張業務"
      },
      "createdAt": "ISO8601",
      "canEdit": true
    }
  ],
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 5
  }
}
```

**新增互動紀錄**

- 端點：`POST /api/v1/c360/customers/:customerId/interactions`
- Request Body：
```json
{
  "interactionType": "phone",
  "interactionAt": "ISO8601",
  "summary": "說明內容",
  "outcome": "處理結果（選填）"
}
```

**編輯互動紀錄**

- 端點：`PATCH /api/v1/c360/customers/:customerId/interactions/:interactionId`
- Request Body：同新增（全欄位可修改）
- 錯誤（403）：非建立者本人，或超過 24 小時編輯期限

## 測試案例

| # | 測試案例 | 預期結果 |
|---|---------|---------|
| 1 | 業務角色進入客戶 360 頁面 | 顯示「互動紀錄」區段與「新增互動紀錄」按鈕 |
| 2 | 後端作業角色進入客戶 360 頁面 | 不顯示「互動紀錄」區段 |
| 3 | 新增互動紀錄（類型：電話，填寫所有欄位）| 紀錄建立成功，列表頂部顯示新紀錄 |
| 4 | 新增時未填寫「摘要」即點儲存 | 顯示「請輸入摘要」錯誤提示，不送出請求 |
| 5 | 業務 A 新增紀錄，業務 B 查看同客戶 | 業務 B 看不到業務 A 的紀錄 |
| 6 | 主管查看同客戶的互動紀錄 | 看到業務 A、業務 B 的所有紀錄，各紀錄標示記錄人 |
| 7 | 紀錄建立未超過 24 小時，建立者點「編輯」 | 開啟編輯表單，修改後儲存成功 |
| 8 | 紀錄建立超過 24 小時 | 不顯示「編輯」按鈕 |
| 9 | 主管查看他人紀錄（超過 24 小時） | 不顯示「編輯」按鈕（稽核保護） |
| 10 | 任何角色查看互動紀錄列表 | 無「刪除」按鈕，紀錄永久保存 |
| 11 | 互動紀錄超過 20 筆 | 底部顯示分頁控制元件 |
| 12 | 未登入呼叫 API | 回傳 401 |
