Banner（月跑鎖定 / 警告條）

資訊提示

用於跨頁面的長期提示，例如：「PROD_KIND 由代碼維護管理，前往代碼維護」

分派執行中（assignment_run.status = running）

所有寫入功能（新增 / 編輯 / 停用）已暫時鎖定，鎖定將於月跑完成後自動解除（對應 409 ASSIGNMENT_RUN_ALREADY_RUNNING / SCORING_VERSION_LOCKED）

操作失敗

用於頁面層級的錯誤提示（非 toast），例如載入失敗、批次儲存失敗

使用準則： Info banner = 藍底，長期說明 / 跳轉提示； Month Run Lock 警告 = 琥珀底，搭配所有寫入按鈕 disabled； Error banner = 紅底，頁面層級錯誤（一過性錯誤用 Toast）
