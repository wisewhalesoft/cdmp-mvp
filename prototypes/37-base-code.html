F075 v1.5 — POOLDATA 篩選欄位白名單

管理可作為名單條件的 OBPOOLDATA 欄位；每欄位標記 field_type（categorical / numeric / date），驅動 F050/F051 名單表單之條件元件型態。 停用為軟刪除（is_active = false），不回溯既有名單條件（BR-3）。 資料表 pooldata_field_whitelist。

總計 7 · 啟用 6 / 停用 1
column_name display_name field_type columnDescription 狀態 操作

F075 v1.5 商業規則摘要

  • BR-1：column_name 為唯一鍵，新增時不分啟用 / 停用一律檢查重複（違反回 409 POOLDATA_FIELD_DUPLICATE）。
  • BR-3：停用「不回溯」既有名單條件，F050/F051 寫入時驗證 is_active = true；F048 列表頁讀取既有名單時不阻擋。
  • BR-4：field_type 由 categorical 改為其他類別時，不自動刪除 F076 既有可選值（軟停用，deactivation_reason = 'field_type_changed'）。
  • BR-8（v1.5）：list_period_start / list_period_end / list_interval 為一級保留欄位，禁止入白名單（J8）。

F076 v1.5 — 類別型欄位可選值

針對 F075 白名單中 field_type = 'categorical' 的欄位維護可選值（option_value + option_label），供 F050/F051 名單表單之多選元件動態載入。 v2.1 起 caseyear / case_status / prod_kind / spec_tp / settle_src 之可選值統一在此維護（F068 廢除後）。

    當前欄位： caseyear （進件 / 滿期年數）
    option_value option_label 狀態 停用原因 操作

    F076 v1.5 商業規則摘要

    • BR-1：(column_name, option_value) 複合唯一鍵；違反回 422 OPTION_VALUE_DUPLICATE。
    • BR-3 / BR-4：停用「不回溯」既有名單；inactive 值保留供歷史追溯與「上月複製」UI 警示。
    • v1.5 新增：caseyear / case_status / prod_kind / spec_tp / settle_src 之可選值統一在此管理（取代 F068 ob_code_df）。
