F076 v1.1 — 類別型欄位可選值管理

針對 F075 白名單中 field_type = 'categorical' 的欄位維護可選值（option_value + option_label），供 US-106 新名單定義表單之多選元件動態載入。 停用為軟刪除（is_active = false），不回溯既有名單（BR-3 / BR-10）。 資料表 categorical_field_value。

權限：部長 + Admin 可新增 / 停用 / 啟用；處長 + 業務僅可查看；對非 categorical 欄位呼叫端點回 422 OPTION_FIELD_TYPE_MISMATCH。

欄位 6 啟用值 22 停用值 3

F076 v1.1 商業規則摘要（含 PO 決議 F076-C）

  • BR-1：(column_name, option_value) 複合唯一鍵，新增時不分啟用 / 停用一律檢查重複（違反回 422 OPTION_VALUE_DUPLICATE）。
  • BR-3 / BR-10：停用「不回溯」既有名單；inactive 值保留供歷史追溯，月跑 Stage 1 不阻擋。
  • BR-7（v1.1）：F075 將欄位 field_type 從 categorical 改為其他類別時，本表既有可選值批次軟停用（is_active = false、deactivation_reason = 'field_type_changed'），不 CASCADE 刪除。
  • BR-9：MVP 不支援可選值排序；列表依 option_value 升冪排列。
