計分卡設定操作說明

覆寫式編輯（無草稿、無 rollback），歷史追溯依賴月跑 config 快照（F066）。月跑執行中（assignment_run.status IN pending/running）所有編輯功能將被鎖定（409 SCORING_VERSION_LOCKED）。複雜計分邏輯由 PostgreSQL function fn_calc_tier_level 實作（AD-E07-3）。
